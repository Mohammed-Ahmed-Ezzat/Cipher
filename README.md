# ⚡ CIPHER - Interactive Roadmaps & Hands-On Workshops Studio

A cyberpunk-themed, interactive learning platform engineered for tech students, developers, and engineers. Explore deep career roadmaps, interactive slide decks, and recorded workshop live sessions.

![Cipher Preview](https://raw.githubusercontent.com/Mohammed-Ahmed-Ezzat/Cipher/main/public/favicon.ico)

---

## 🚀 Key Features

- **Cyberpunk UI & Visual Excellence:** Custom-crafted dark glassmorphism, glowing accents, sound effects, and smooth animations.
- **Interactive Career Roadmaps:** Network, Frontend, Backend, Flutter & Mobile, DevOps, Problem Solving, and AI tracks.
- **Interactive Slides Viewer:** Pre-rendered canvas-based local slide decks (`.cipher` / PDF) with zoom, full-screen, page controls, and keyboard navigation.
- **Recorded Hands-On Workshops Studio:** Dual-mode video streaming (Instant Mobile Player & Embedded Player) for Network, Backend, and Frontend tracks.
- **Mobile Optimized & High Performance:** Fast loading, responsive layout, zero third-party cookie issues on mobile Safari/Chrome.
- **Full Search & Filter:** Filter roadmaps by category, level, or keywords in real-time.

---

## 🛠️ Tech Stack

- **Core:** React 18, Vite
- **Styling:** Modular Vanilla CSS, CSS Variables & Design Tokens
- **Icons:** FontAwesome 6 Pro
- **PDF Engine:** Mozilla PDF.js & Custom Canvas Renderer
- **Audio:** Web Audio API sound synthesis

## 🏁 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Mohammed-Ahmed-Ezzat/Cipher.git
cd Cipher
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Build for production
```bash
npm run build
```
